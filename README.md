AI RESUME ANALYSER

This project is an AI-powered Resume Analyzer and ATS Scoring System built using Streamlit that simulates the workflow of modern Applicant Tracking Systems. It automatically classifies resumes into relevant job roles and evaluates how well they match a target job description using semantic similarity, helping users optimize their resumes for specific roles.

The system uses Sentence Transformers to generate dense semantic embeddings that capture the contextual meaning of resume content beyond simple keyword matching. Resume text is extracted, cleaned, and preprocessed before being converted into embeddings, which are then passed to a Support Vector Classifier (SVC) to accurately predict the most suitable job role. To estimate ATS compatibility, the application computes cosine similarity between the embeddings of a resume and a job description, producing an ATS score that reflects their semantic alignment.

The application supports resume uploads in both PDF and DOCX formats and provides real-time job role prediction and ATS scoring through an interactive Streamlit interface. The complete pipeline, from document parsing and preprocessing to embedding generation, classification, and semantic scoring, is integrated into a single end-to-end machine learning application. This project demonstrates practical applications of natural language processing, semantic embedding models, classical machine learning, and interactive ML deployment for real-world recruitment scenarios.
